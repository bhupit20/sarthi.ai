# UX Profile

Generated by `setup-ui-ux-skills`, adapted for SARTHI.AI. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** After the owner's KRAFTDASH design (github.com/bhupit20/Kraftdash): warm paper background with a soft honey glow at the top right, large rounded cards (about 22px), a dark pill for the active navigation item, near-black primary buttons, honey as the accent for highlights and live state, Bricolage Grotesque for titles and Hanken Grotesk for text. Light and dark themes. Two surfaces: the dashboard window (sidebar app, at least 900px wide) and the floating copilot (320–420px wide), read at a glance during live calls.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders (the single soft backdrop glow from KRAFTDASH is allowed; never on buttons or cards)
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** At least 4.5:1 for normal text, 3:1 for large text, borders and UI component boundaries.
- **Touch / focus:** 44×44px minimum targets; visible focus rings; every action reachable by keyboard; global shortcuts for the live session.

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Calm, clear and kind: the user is under pressure on a live call. Short plain words; say what happened and what to do next. All UI text in English.

## Icon library

- **Library:** Lucide
- **Package / path:** No package; icons are inlined as Lucide SVG paths in `src/renderer/ui/icons.tsx`.
- **Notes:** Outline icons at 16–20px, 2px stroke, `currentColor`. Icon-only buttons need an accessible label and a tooltip.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
