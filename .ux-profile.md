# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** The panel is a narrow side panel (about 320–420px wide) read at a glance during a live video call by someone whose second language is English. Clarity beats density: the reply text is the hero, everything else stays quiet. Restrained neutrals, one accent, strong type hierarchy, subtle dividers, soft elevation only where it separates layers. Light and dark mode.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** At least 4.5:1 for normal text, 3:1 for large text, borders and UI component boundaries.
- **Touch / focus:** 44×44px minimum targets for primary actions; visible focus rings on every interactive element; keyboard reachable (Alt+S, Enter to translate).

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Calm, clear and kind: the user is under pressure on a live call. Short plain words, no jargon, no blame in errors; say what happened and what to do next. All UI text in English.

## Icon library

- **Library:** Lucide
- **Package / path:** No package installed; the few icons needed are inlined as Lucide SVG paths in `src/panel/icons.tsx`.
- **Notes:** Outline icons at 16–20px, 2px stroke, `currentColor`. Icon-only buttons need an accessible label.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
